# Experimental Setup

We grow fenugreek in an aeroponic system and compare nutrient solutions with different combinations of three fertilizer compounds. Our testbed is complete.

## Setup information

| Item | Current information |
| --- | --- |
| Crop | Fenugreek |
| Growing method | Aeroponics |
| Nutrient conditions | Controlled nutrient-deficient conditions |
| Fertilizer inputs under study | Calcium nitrate, potassium sulphate, and ammonium phosphate |
| Growing containers | 8 Dutch buckets with mist sprayers |
| Controller | ESP32 |
| Switching | 8-channel relay module |
| Power supply | 12 V, 10 A DC adapter |
| Pumps | 8 × 12 V diaphragm pumps, rated 125 PSI |
| Misting control | ESP32 firmware controlling the misting cycle |

The system uses a grow chamber, nutrient reservoir, spray manifold, and return path. Specific camera details and operating parameters are not recorded here.
