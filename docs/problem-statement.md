# Problem Statement

In our controlled fenugreek aeroponics experiment, we need a systematic way to document plant appearance over time under different nutrient-solution fertilizer conditions and identify visible deficiency symptoms associated with those conditions.

The project addresses this need by:

1. Using the completed aeroponic testbed to grow fenugreek under controlled conditions.
2. Collecting and preparing a time-series image dataset linked to the corresponding fertilizer treatments; this work is in progress.
3. Developing and evaluating an image-based model to identify deficiency symptoms associated with the tested conditions; this work is planned and has not yet begun.

The treatments vary the presence or absence of calcium nitrate, ammonium phosphate, and potassium sulphate. They represent fertilizer-compound combinations, not experiments that isolate individual nitrogen, phosphorus, or potassium elements. The project has not yet produced a trained model or model evaluation results.
