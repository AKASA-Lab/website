# Dataset Preparation

We are preparing a time-series image dataset. Keep source images and their experimental records linked throughout preparation.

## Preparation checklist

- Preserve original images and record any derived files separately.
- Confirm image identifiers and metadata fields are consistent.
- Check that treatment code, plant, bucket, and time-point labels match the experimental records.
- Record any exclusions and their reasons.
- Document image resizing, cropping, normalization, annotation, or other transformations if applied.
- Define data partitions by plant, keeping designated test plants separate from training and tuning data.

## Details to confirm

Specify file formats, directory structure, quality checks, annotations, preprocessing steps, dataset versioning, and access or licensing terms only after they are established.
