# Project Objectives

## Three project goals

1. Create a testbed for aeroponic fenugreek experiments.
2. Build a time-series image dataset under fertilizer-omission treatments.
3. Develop and evaluate an image-based model that can identify deficiency symptoms associated with our tested fertilizer conditions. This model is central to our goal of intelligent nutrient management for aeroponics.

The testbed is complete, dataset work is in progress, and model development has not yet begun. The dataset and model are both core research goals: the dataset provides the labelled images needed to develop and evaluate the deficiency-identification model. See [Project Progress](#/docs/project-progress).

## Supporting study aims

We document the experiment and observations over time so the dataset can support subsequent image-based nutrient management. Our fertilizer conditions vary the presence or absence of calcium nitrate, potassium sulphate, and ammonium phosphate; we do not isolate individual nitrogen, phosphorus, or potassium elements.
